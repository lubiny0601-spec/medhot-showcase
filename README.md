## 这是什么

每天早晨，它把 41 个信源里过去 24 小时的内容收进来，先粗筛一遍、再让模型独立评两次分，
挑出真正值得看的十几条，写成中文标题和摘要；把不同来源说的同一件事聚成一个事件；
最后出一份按影响力排序的日报。

**给谁看**：药企的市场经理、销售经理、准入与商务人员——需要每天花五分钟搞清楚
「我的品类今天有没有新变化」的人。

**解决什么**：不是信息不够，是噪音太多。政策原文藏在政府站列表第七页，集采文件只在省级平台挂三天，
竞品的 BD 消息要等媒体报道才知道——等你看到，已经晚了一步。

## 会收什么，会丢掉什么

这不是关键词匹配，是一份写给「中国准入与竞争格局」的编辑标准。
**学术期刊、预印本、基础机制研究不进来；讲不清跟中国准入关系的海外事务降权。**

| 会重点收 | 会排除 |
|---|---|
| 药品的公司动态与业绩、BD 授权与交易 | 医疗器械与耗材 |
| 报产、获批、上市与撤市 | 中药饮片与品种保护 |
| 医保、商保支付与价格机制 | 地方执行细则（某市编码切换之类） |
| 集采与省级招采平台动态 | 学术论文与机制研究 |
| 专利、合规与诉讼、竞品节奏 | 跟中国准入无关的海外事务 |

全部实测可抓才收进来。抓不到的不写进名单——名单好看但跑不出内容，等于没有。

| 省级集采平台 | 4 | 北京医保局、江苏阳光采购、广东药品交易中心、天津药采中心 |

公告通道是这套站最值钱的部分——**集采拟中标、BD 授权这类消息，公告比新闻早一天**。

## 怎么选出来

按 60 条人工标注反复扫出来的一致性门槛，分三档。改一次提示词，就要把库里的存量重评一遍，
否则新旧口径会混在一起。

| 档位 | 大致对应 |
|---|---|
| **T1** | 直接改变竞争格局或支付口径，必看 |
| **T1.5** | 有明确动作的品类与公司动态 |
| **T2** | 值得知道的行业背景 |

**抗菌药与抗感染是核心题材，不是边缘。** 集采、医保支付、分级管理、处方点评、耐药监测、
重点品类竞争，都按正常权重甚至加权处理——不因为「这是海外事务」就降一档。

## 它不做什么

- **不替你判断商业价值。** 它只保证「这条消息跟中国医药准入有关」，影响多大要看你的产品线。
- **不追学术。** 要看机制和临床数据，去看期刊，这个站不干那件事。
- **不做全覆盖。** NMPA、卫健委上了防爬网关，纯抓取走不通，用行业媒体替补——官方原文可能迟一步。
