# MedHOT 介绍页

MedHOT 的对外介绍页，用 GitHub Pages 托管。只有一个文件，零依赖。

- **在线页面**：https://lubiny0601-spec.github.io/medhot-showcase/
- **站点本身**：https://medhot.netlify.app
- **代码仓库**：私有，未公开（信源配置与选稿口径属于个人 KnowHow）

## 这个页面是什么

给药企市场、销售、准入与商务同事看的单页说明：MedHOT 盯什么、信源从哪来、
怎么筛选、有哪些边界。不是代码仓库，代码不开源。

## 改内容

直接改 `index.html`，push 到 `main` 分支，Pages 会在一两分钟内自动更新。

配色与主站一致，都是 token 化的（`index.html` 顶部 `:root`）：

| 用途 | 色值 |
|---|---|
| 页面底色 | `#f5f7fa` |
| 文字墨色 | `#161d27` |
| 主色（深墨蓝） | `#23527c` |
| 深色区 | `#0e1a26` |
| 亮蓝点缀 | `#7fb0e0` |

引擎基于 [AIHOT](https://github.com/KKKKhazix/AIHOT)（MIT）改造。
